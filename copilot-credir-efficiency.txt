I found something particularly relevant: the VS Code engineering team published an article on June 17, 2026, specifically about improving token efficiency in GitHub Copilot.

This is not just a general recommendation. It describes actual engineering changes to the Copilot agent infrastructure. 

https://code.visualstudio.com/blogs/2026/06/17/improving-token-efficiency-in-github-copilot





Here are the most interesting improvements.
A. Prompt caching optimization
Cost optimization
When you use Copilot Chat, requests can contain repeated information:
- System instructions.
- Repository context.
- Tool definitions.
- Previous conversation messages.
- File contents.
Instead of processing all repeated information from scratch, supported models can reuse cached context.

Why this matters:

Suppose you're debugging an API across 15 chat messages. Some instructions and context are repeated between requests.

With prompt caching, supported models can reuse previously processed context, making repeated input cheaper.

VS Code's engineering team has improved cache retention and cache breakpoint placement.

For supported models, cached input can cost up to 10 times less than uncached input, depending on the model's pricing. 

https://docs.github.com/en/copilot/tutorials/optimize-ai-usage?utm_source=chatgpt.com



B. Tool Search – loading tools only when required
Very interesting improvement
This is particularly useful in Agent mode.

Imagine Copilot has access to:
- Read files
- Edit files
- Terminal
- Search
- Git
- MCP servers
- Other extensions
Traditionally, tool definitions can consume context even when the agent doesn't need all those tools.

The newer tool-search approach allows Copilot to discover and load relevant tool definitions when required instead of including every complete definition upfront.

Result: Less unnecessary context sent to the model.

In VS Code's reported experiments:
Model	Reduction in median tokens per turn
GPT-5.4	9.81%
GPT-5.5	8.61%

These are experimental measurements reported by the VS Code team, not guaranteed savings for every user. 

Visual Studio Code



C. Background Todo Agent
Experimental feature
Introduced in VS Code 1.119.

When an agent works on a large task, it maintains a todo list.

Previously, the main agent could spend additional model calls managing and updating that list.

The background Todo Agent moves that responsibility to a lightweight background agent.

This allows the primary model to focus on implementation instead of spending additional tokens managing progress.

Setting:
{
  "github.copilot.chat.agent.backgroundTodoAgent.enabled": true
}


This is particularly interesting for multi-step development tasks.

2. Which VS Code version should you use?
There are several relevant milestones:
VS Code version	Relevant improvement
1.118	Prompt caching efficiency improvements
1.119	Experimental background Todo Agent
1.120	Minimum version recommended by GitHub for accurate usage-based billing information
Latest Stable	Recommended to receive the newest Copilot improvements

GitHub explicitly recommends VS Code 1.120 or later for usage-based billing. Older versions may display incorrect model pricing and inaccurate usage information.

4. Other important practices that can save credits
These aren't necessarily version-specific, but they work alongside the newer improvements.
Practice	Why it helps
Start a new chat for unrelated tasks	Prevents irrelevant history from accumulating
Reuse an existing chat for the same task	Avoids repeating relevant explanations
Avoid attaching entire repositories	Reduces unnecessary context
Select only relevant files	Keeps prompts focused
Use the appropriate model	Avoids paying more for simple tasks
Plan before implementation	Reduces unnecessary agent exploration
Avoid unnecessary MCP tools	Reduces tool-definition overhead
Don't repeatedly change reasoning settings	Helps preserve cache reuse

GitHub also recommends separating research, planning and implementation into focused phases.

This is worth testing because it can help identify opportunities to reduce unnecessary consumption.
